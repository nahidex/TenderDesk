# TenderEval

Folder Explorer + PDF/Image Preview + Evaluation Checklist — টেন্ডার/RFQ মূল্যায়নের জন্য একটা সিঙ্গেল-পেজ টুল। বাম পাশে ফাইল ব্রাউজার, মাঝখানে PDF/ছবি প্রিভিউ, ডান পাশে Yes/No/N/A ইভ্যালুয়েশন চেকলিস্ট — সব একসাথে এক স্ক্রিনে।

> নাম "TenderEval" শুধু একটা সাজেশন — চাইলে `index.html`-এর `<title>` ট্যাগ ও এই ফাইলের প্রথম লাইন বদলে নিজের পছন্দমতো নাম দিতে পারেন।

## ✨ বৈশিষ্ট্য

- **ফোল্ডার ব্রাউজার** — দুই মোডে কাজ করে:
  - 🖥️ **লোকাল মোড** — ব্রাউজারের File System Access API দিয়ে আপনার কম্পিউটারের যেকোনো ফোল্ডার সরাসরি ব্রাউজ করা যায় (কোনো আপলোড লাগে না)
  - 🌐 **সার্ভার মোড** — `server.py` (Flask) চালিয়ে সার্ভারের ফোল্ডার নেটওয়ার্কের যেকোনো ডিভাইস থেকে ব্রাউজ করা যায়
- **PDF ও ইমেজ প্রিভিউ** — `.pdf`, `.jpg/.jpeg`, `.png`, `.gif`, `.webp`, `.bmp`, `.svg` ফাইলে ক্লিক করলে মাঝখানে প্রিভিউ দেখায়, ডাউনলোড লিংকও থাকে
- **৩-ট্যাব ইভ্যালুয়েশন চেকলিস্ট**
  1. Submission Checklist (ফর্ম/ডকুমেন্ট × কোম্পানি)
  2. Document Checklist (কোম্পানি × ডকুমেন্ট)
  3. Technical Compliance (গ্রুপ করা প্রোডাক্ট স্পেক × কোম্পানি)
- **🔗 Source trace** — কোনো Yes/No/N/A সিলেক্ট করার সময় ভিউয়ারে যেই PDF/ছবি খোলা ছিল, তার সাথে লিংক হয়ে সেভ হয়; পরে 🔗 বাটনে ক্লিক করলে সরাসরি সেই ফাইলটাই আবার খুলে যায়
- **Excel Import** — `.xlsx` ফাইল থেকে Submission/Document/Technical Compliance-এর পুরো স্ট্রাকচার (কোম্পানি, আইটেম, ফিল-আপ করা ভ্যালু) অটোমেটিক বসিয়ে দেয় — সারি/কলাম সংখ্যা যা-ই হোক ডাইনামিক্যালি পড়ে
- **📋 Sample Excel ডাউনলোড** — সঠিক ফরম্যাট বোঝার জন্য একটা নমুনা `.xlsx` (নির্দেশনা শীটসহ) ডাউনলোড করা যায়
- **CSV / Excel এক্সপোর্ট** — তিনটা ট্যাবের ডেটা একসাথে এক্সপোর্ট করা যায়
- **রিসাইজেবল ও কোলাপসিবল প্যানেল** — বাম/ডান প্যানেল ড্র্যাগ করে ছোট-বড় করা যায়, ◀/▶ বাটনে ক্লিক করে হাইড/শো করা যায় (অবস্থা লোকাল স্টোরেজে সেভ থাকে)
- **অটো-সেভ** — সব ইভ্যালুয়েশন ডেটা ব্রাউজারের localStorage-এ সয়ংক্রিয়ভাবে সেভ হয় (কোনো ডাটাবেস/সার্ভার লাগে না)

## 📁 প্রজেক্ট স্ট্রাকচার

```
.
├── index.html        # পুরো UI + লজিক (single-file frontend)
├── server.py          # সার্ভার মোডের জন্য Flask backend (ঐচ্ছিক)
└── .env.example        # সার্ভার কনফিগারেশনের নমুনা (রিনেম করে .env বানাতে হবে)
```

## 🚀 চালানোর নিয়ম

### শুধু লোকাল মোডে (সবচেয়ে সহজ)

`index.html` ফাইলটা সরাসরি Chrome বা Edge-এ খুললেই "🖥️ লোকাল ফোল্ডার সিলেক্ট করুন" কাজ করবে (তবে PDF এম্বেড কিছু ব্রাউজারে `file://` থেকে সরাসরি ভালো কাজ নাও করতে পারে — নিচের সার্ভার মোড ব্যবহার করাই ভালো)।

### সার্ভার মোডে (রেকমেন্ডেড)

**প্রয়োজনীয়তা:** Python 3 এবং Flask

```bash
pip install flask
```

**চালানো:**

```bash
python3 server.py
```

ডিফল্টে সার্ভার `0.0.0.0:5000`-এ চলবে। ব্রাউজারে খুলুন:

```
http://localhost:5000
```

অথবা একই নেটওয়ার্কের অন্য ডিভাইস থেকে:

```
http://<সার্ভারের-IP>:5000
```

### কনফিগারেশন (.env)

`.env.example` ফাইলটা রিনেম করে `.env` বানান (dot দিয়ে শুরু, `.example` বাদ দিয়ে), তারপর দরকারমতো এডিট করুন:

```env
PORT=8080
HOST=0.0.0.0
BROWSE_ROOT=/path/to/your/folder
```

`.env` ফাইলটা `server.py`-র পাশে থাকলে অটোমেটিক পড়া হয়ে যাবে — কোনো এক্সট্রা প্যাকেজ (`python-dotenv`) ইনস্টল করার দরকার নেই। টার্মিনালে সরাসরি environment variable দিয়ে চালালে সেটা `.env`-এর চেয়ে অগ্রাধিকার পাবে:

```bash
PORT=8080 python3 server.py
```

## 📖 ব্যবহার

### ১. ফোল্ডার ব্রাউজ করা

- **🖥️ লোকাল ফোল্ডার সিলেক্ট করুন** — নিজের কম্পিউটারের যেকোনো ফোল্ডার সিলেক্ট করুন (শুধু Chrome/Edge; পেজ `https://` বা `localhost` থেকে লোড হতে হবে)
- **🌐 সার্ভার ফোল্ডার ব্রাউজ করুন** — `server.py`-র পাশের (বা `.env`-এ দেওয়া `BROWSE_ROOT`) ফোল্ডার ব্রাউজ করুন
- ফাইলে ক্লিক করলে মাঝখানে প্রিভিউ খুলবে; কোম্পানির ডকুমেন্ট/ছবি খুলে ডান পাশে সংশ্লিষ্ট চেকলিস্ট আইটেমে Yes/No/N/A সিলেক্ট করলে সেটা এই ফাইলের সাথে লিংক হয়ে যাবে

### ২. Excel থেকে চেকলিস্ট বানানো

1. টুলবার থেকে **📋 Sample Excel** ডাউনলোড করে ফরম্যাট দেখে নিন
2. নিজের টেন্ডারের তথ্য দিয়ে ঠিক একই ফরম্যাটে ৩টা শীট (নামে "Submission" / "Document" / "Technical"বা "Compliance" শব্দ থাকতে হবে) বানান
3. **📥 Import Excel**-এ ক্লিক করে ফাইলটা সিলেক্ট করুন
4. সামারি দেখে কনফার্ম করলে বর্তমান চেকলিস্ট মুছে নতুন ডেটা বসে যাবে

**খেয়াল রাখুন:** তিনটা শীটে কোম্পানির নাম হুবহু এক বানানে (case-insensitive) লিখুন, নাহলে দুটো আলাদা কোম্পানি হিসেবে ইম্পোর্ট হয়ে যাবে।

### ৩. ইভ্যালুয়েশন এক্সপোর্ট করা

টুলবার থেকে **📄 CSV** বা **📊 Excel** — তিনটা ট্যাবের ডেটা একসাথে এক্সপোর্ট হবে।

### ৪. প্যানেল ছোট-বড়/হাইড করা

প্যানেলের মাঝের ধূসর বার ড্র্যাগ করলে সাইজ বদলাবে; বারের মাঝের ◀/▶ বাটনে ক্লিক করলে পুরো প্যানেল হাইড/শো হবে।

## ⚠️ সীমাবদ্ধতা / নোট

- **ব্রাউজার সাপোর্ট:** লোকাল ফোল্ডার মোড শুধু Chrome/Edge-এ কাজ করে (File System Access API); Firefox/Safari-তে সাপোর্ট নেই — সেক্ষেত্রে সার্ভার মোড ব্যবহার করুন
- **ডেটা কোথায় থাকে:** ইভ্যালুয়েশন চেকলিস্টের সব ডেটা (Yes/No/N/A, কোম্পানি লিস্ট ইত্যাদি) ব্রাউজারের `localStorage`-এ থাকে — অন্য ব্রাউজার/ডিভাইস থেকে সিঙ্ক হয় না, ব্রাউজার ডেটা ক্লিয়ার করলে মুছে যাবে (তাই মাঝেমধ্যে 📊 Excel এক্সপোর্ট করে ব্যাকআপ রাখা ভালো)
- **সিকিউরিটি:** `server.py`-র `/api/list` ও `/api/file` পাথ-ট্রাভার্সাল আটকায় (`BROWSE_ROOT`-এর বাইরে যেতে পারবে না), কিন্তু এটা কোনো অথেন্টিকেশন/অ্যাক্সেস-কন্ট্রোল যোগ করে না — `BROWSE_ROOT` ফোল্ডারে যা আছে, নেটওয়ার্কে যে কেউ (যদি সার্ভারের অ্যাড্রেস জানে) সেটা দেখতে পারবে। সংবেদনশীল ফাইল ওই ফোল্ডারে না রাখাই ভালো, অথবা শুধু ট্রাস্টেড নেটওয়ার্কে চালান
